## 이게 뭔가요

도로 위계부터 발전소 배치 방향, 학교 도입 타이밍, 매립지 위치까지 — 전부 **숫자와 근거**로 설명하는 단일 HTML 공략집입니다. 외부 의존성은 한글 웹폰트(Pretendard) 하나뿐이고, 나머지는 전부 파일 하나에 들어 있습니다.

### 특히 5장 — "도로를 어떻게 늘려야 하죠?"

6→4→2차선 위계는 알겠는데 **마을을 키우면서 실제로 도로를 어떻게 확장하는지**가 가장 막히는 지점입니다. 5장은 그것만 다룹니다.

- 인구 500 → 10만까지 **같은 도시가 자라는 5단계 도면** (1단계에서 그은 골격이 5단계까지 그대로 남습니다)
- "지네 도시" 반면교사 — 국지도로를 계속 이어붙이면 어떻게 되는가
- **도로 승격 규칙** — 언제 무엇을 몇 차선으로 올리나 (그리고 왜 넓히는 게 대개 답이 아닌가)
- **표준 블록 치수** — 콜렉터 간격 ≈20셀, 구획 깊이 최대 6칸(48m)
- **산업지구 도로 설계** — 좋은 예/나쁜 예 도면 + 루프형·빗살형·막다른골목형 3종 패턴 비교

### 특징

- **기준 패치 명시** — Economy 2.0(1.1.5f1, 2024-06) 이후 ~ 2025–2026 현행 패치. CS1에서 통하던 요령 중 CS2에서 반대로 작동하는 것들을 본문에서 명시적으로 짚습니다.
- **불확실한 수치는 정직하게 표기** — 패치마다 바뀌는 값은 `≈` 또는 "(패치에 따라 변동)"으로 표시했습니다. 최종 기준은 항상 게임 내 건물 정보 패널입니다.
- **증상 기반 검색** — "돈이 마이너스", "임대료가 너무 높음", "소각장을 지었는데 쓰레기가 쌓임" 같은 실제 증상에서 원인으로 역추적할 수 있습니다.
- 다크 모드 자동 지원, 모바일 대응, 스크롤 위치 추적 목차.

정적 서버로 띄우고 싶다면:

```bash
python -m http.server 4188
```

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages** 이동
2. **Source**를 `Deploy from a branch`로 설정
3. Branch를 `main` / `/ (root)`로 지정하고 저장
4. 1~2분 뒤 `https://g23252a-svg.github.io/ssk2/` 에서 접속 가능
