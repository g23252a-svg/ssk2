## 이게 뭔가요

도로 위계부터 발전소 배치 방향, 학교 도입 타이밍, 매립지 위치까지 — 전부 **숫자와 근거**로 설명하는 단일 HTML 공략집입니다. 외부 의존성은 한글 웹폰트(Pretendard) 하나뿐이고, 나머지는 전부 파일 하나에 들어 있습니다.

### 도로·지구 설계는 3개 장으로 분리했습니다

이 게임에서 가장 많이 막히는 지점이라 별도 파트로 뺐습니다.

**4장 — 도로 설계 & 교통 공학**
- 도로 위계 4단계, CS2 차선 선택 AI(연령별 경로 비용)
- **위계별 접속 간격 종합표** — 고속도로 IC↔IC, 램프 종점↔첫 신호, 간선 신호 간격, 인접 도로 최대 간격
- **역할별 도로 선택표** — 어디에 6차선을 쓰고 어디에 2차선을 쓰나
- 회전교차로 vs 신호등 판단(교통 균형 도해), 인터체인지 6종 도면, 주차 배회 교통

**5장 — 도시 확장 로드맵 & 산업지구**
- 인구 500 → 10만까지 **같은 도시가 자라는 5단계 도면** (1단계 골격이 5단계까지 남습니다)
- "지네 도시" 반면교사, 도로 승격 규칙, 표준 블록 치수
- **산업지구 도로 설계** — 좋은 예/나쁜 예 + 루프형·빗살형·막다른골목형 3종
- **화물 전용 IC 상세** — 고속도로 상·하행 4개 램프 동선을 다 그린 도면

**6장 — 광역 연결 & 도로변 채우기**
- 타일을 샀을 때 새 땅을 잇는 법 (간선 연장 + 새 폐루프)
- **지구 간 거리별 연결 등급표** — 500m / 1.5km / 그 이상
- **밀도 구배 단면도** — 고속도로변부터 국지도로변까지 무엇을 채우나
- 신시가지 패턴 3종(직렬형·방사형·링+방사형), 지구(District) 도구 활용

### 🧭 맵 시작 진단기 (1-4절)

새 맵을 켤 때마다 "여기서 뭘 어디에 지어야 하나"를 대신 판단해 줍니다.

- **기본 12개 맵 프리셋** — 맵을 고르면 자원·외부연결·겨울기온이 자동 입력됩니다
- 맵 안에서 직접 확인할 4가지(**바람 방향·강 유향·지하수·협곡**)만 클릭하면
- **주거/산업 방향, 취수·배수 위치, 단계별 도로 차선 계획, 추천 발전소, 초반 흑자 루트, 화물 전략**을 즉석에서 출력

예를 들어 Lakeland를 고르고 바람이 동쪽으로 빠진다고 하면 → 산업은 동쪽 끝, 주거는 서쪽, 강이 없으니 하수 처리장 준비, 지하수가 있으면 지열 발전, 겨울 -15°C이므로 발전량 +50~100% 여유, 선박 연결이 없으니 해상 무역 계획 금지 — 이런 식으로 나옵니다.

### 키워드 검색

상단 검색창에 낱말을 넣으면 **모든 소제목·도해 제목·경고 상자·접이식 항목**(약 500개 항목)에서 찾아 해당 위치로 바로 이동합니다. `/` 또는 `Ctrl+K`로 검색창에 포커스, `↑↓`로 이동, `Enter`로 열기, `Esc`로 닫기.

### 특징

- **기준 패치 명시** — Economy 2.0(1.1.5f1, 2024-06) 이후 ~ 2025–2026 현행 패치. CS1에서 통하던 요령 중 CS2에서 반대로 작동하는 것들을 본문에서 명시적으로 짚습니다.
- **불확실한 수치는 정직하게 표기** — 패치마다 바뀌는 값은 `≈` 또는 "(패치에 따라 변동)"으로 표시했습니다. 최종 기준은 항상 게임 내 건물 정보 패널입니다.
- **증상 기반 검색** — "돈이 마이너스", "임대료가 너무 높음", "소각장을 지었는데 쓰레기가 쌓임" 같은 실제 증상에서 원인으로 역추적할 수 있습니다.
- 다크 모드 자동 지원, 모바일 대응, 스크롤 위치 추적 목차.
